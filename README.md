# 💰 Мои Финансы

Современное веб-приложение для iPhone с учётом доходов/расходов, диаграммами и аналитикой.

---

## 🚀 Как установить на iPhone (3 способа)

### Вариант 1: GitHub Pages (рекомендую!)

**Шаг 1. Создай репозиторий**
```bash
# У тебя уже есть папка finance-app, теперь загрузи на GitHub:

cd /путь/к/finance-app

git init
git add .
git commit -m "Первая версия финансового приложения"

# Создай новый репозиторий на github.com (назови finance-app)
# Потом подключи его:

git remote add origin https://github.com/твой-username/finance-app.git
git branch -M main
git push -u origin main
```

**Шаг 2. Включи GitHub Pages**
1. Зайди в **Settings** твоего репозитория
2. Найди раздел **Pages** (слева в меню)
3. В **Source** выбери ветку `main` → папка `/ (root)`
4. Нажми **Save**
5. Через минуту появится ссылка: `https://твой-username.github.io/finance-app/`

**Шаг 3. Установи на iPhone**
1. Открой Safari на iPhone
2. Перейди по ссылке `https://твой-username.github.io/finance-app/`
3. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх)
4. Прокрути вниз → выбери **"На экран Домой"**
5. Нажми **Добавить**
6. Готово! 🎉 Иконка появилась на рабочем столе

---

### Вариант 2: Netlify Drop (самый быстрый)

1. Зайди на **netlify.com** (регистрация бесплатная)
2. Перетащи папку `finance-app` прямо в окно браузера (Drag & Drop)
3. Получишь ссылку типа `https://random-name-123.netlify.app`
4. Открой в Safari на iPhone → добавь на экран

**Плюс:** можешь изменить адрес в настройках Netlify на что-то типа `pavel-finance.netlify.app`

---

### Вариант 3: Vercel (для продвинутых)

```bash
# Установи Vercel CLI
npm install -g vercel

# Зайди в папку проекта
cd finance-app

# Задеплой
vercel

# Следуй инструкциям → получишь ссылку
```

Открой ссылку в Safari → добавь на экран.

## 📱 Как пользоваться

### Добавить доход
- Открой вкладку **Доходы**
- Выбери категорию (зарплата, фриланс, премия...)
- Введи сумму
- (Опционально) добавь описание
- Нажми **Добавить доход**

### Добавить расход
- Открой вкладку **Расходы**
- Выбери категорию (продукты, кредиты, здоровье...)
- Введи сумму
- Нажми **Добавить расход**

### Быстрое добавление
- Нажми кнопку **+** справа внизу
- Выбери **Доход** или **Расход**
- Откроется нужная форма

### Посмотреть статистику
Вкладка **Обзор**:
- Общий баланс
- Диаграмма «куда уходят деньги» (пончик)
- График за последние 30 дней
- Последние операции

Вкладка **Анализ**:
- Детальная разбивка по категориям (столбцы)
- Фильтр по периодам
- Экспорт данных

### Экспорт данных
1. Вкладка **Анализ** → прокрути вниз
2. Нажми **Экспорт в CSV**
3. Файл сохранится в загрузках
4. Можешь открыть в Excel или сохранить в заметки как бэкап

## 🎨 Что под капотом

- **HTML5** + **CSS3** (переменные, анимации, градиенты)
- **Vanilla JavaScript** (без фреймворков)
- **Chart.js 4.4** для диаграмм
- **LocalStorage** — все данные только на твоём телефоне
- **PWA** (Progressive Web App) — работает как нативное приложение
- **Service Worker** — работает офлайн

**Размер:** ~90 КБ (вся логика + стили)  
**Зависимости:** только Chart.js (подгружается с CDN)

## 🔒 Безопасность

✅ Все данные хранятся ТОЛЬКО на твоём iPhone  
✅ Ничего не уходит на сервер  
✅ Нет регистрации, нет аккаунтов  
✅ Нет рекламы, нет трекинга

## 💡 Идеи для улучшения (если захочешь доработать)

1. **Бюджеты** — установить лимит на категорию, например «Продукты ≤ 20 000 ₽/мес»
2. **Повторяющиеся платежи** — автоматически добавлять зарплату 5-го числа или коммуналку 25-го
3. **Облачная синхронизация** — подключить Firebase или Supabase для синхронизации между устройствами
4. **Цели** — копить на что-то конкретное (отпуск, машина)
5. **Сравнение месяцев** — сколько потратил в сентябре vs октябре
6. **Уведомления** — напоминания добавить траты вечером
7. **Тёмная/светлая тема** — переключатель

## 🐛 Если что-то не работает

**Иконка не появилась на экране:**
- Убедись, что добавлял через Safari (Chrome на iOS не поддерживает PWA)
- Попробуй перезагрузить страницу и добавить снова

**Данные пропали:**
- Проверь, что используешь один и тот же браузер (Safari)
- Не чистил кэш браузера?
- На всякий случай делай экспорт раз в неделю

**Диаграммы не отображаются:**
- Проверь интернет (Chart.js грузится с CDN при первом запуске)
- После первой загрузки работает офлайн
